Tecnologías utilizadas

🐙

GitHub

Almacena y administra el código fuente de nuestro proyecto utilizando Git.

⚙️

GitHub Actions

Automatiza el despliegue del sitio cada vez que publicamos cambios en la rama main.

🔥

Firebase Hosting

Aloja nuestro sitio web y permite acceder a él públicamente mediante una URL segura.
